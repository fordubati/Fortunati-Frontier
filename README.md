# The Fortunati Frontier

Markets, politics & Montana, every morning. Published at https://fordubati.github.io/Fortunati-Frontier/

- `_posts/` holds editions, written automatically each morning by a scheduled Claude Code routine.
  - Daily briefs (Mon–Sat): `YYYY-MM-DD-daily-brief.md`, `categories: [daily]`
  - Weekly editions (Sun): `YYYY-MM-DD-weekly-edition.md`, `categories: [weekly]`
- Feeds: `/feed.xml` (all), `/feed/daily.xml`, `/feed/weekly.xml`, which the email service uses.
- `EDITORIAL_GUIDE.md` is the house style and section structure the routine follows.

This repository is public. Nothing personal (applications, résumés, subscriber emails, lessons) belongs here.
